# flowers

A little garden for my best friends.

Tap the meadow to plant flowers and watch them grow. Drag across the garden to make wind, tap a bloom for butterflies and petals. Grow eight blooms to open a letter, then press **Play the surprise**.

The piano cover (Rathinamo) starts on your first tap, and the flowers move to its notes.

Open `index.html` in a browser, or serve this folder with any static host (for example GitHub Pages).
